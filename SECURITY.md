# Security policy

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/bycavii/expirely-action/security/advisories/new). Do not open a public issue.

Reports about the action itself belong here: script injection through inputs, an archive that runs without being verified, or a token sent where it should not go. Reports about the expirely binary belong to [bycavii/expirely-cli](https://github.com/bycavii/expirely-cli/security/advisories/new).

Only the latest release of the current major version receives fixes.
